## ✨ Features

| Feature | Description |
|---------|-------------|
| 🏰 **14 Tower Types** | Cannon, Laser, Crystal, Flamethrower, Poison, Ice, Lightning, Minigun, Sniper, Rocket, Mortar, Arcane, Tesla, Dragon |
| 👾 **11 Enemy Types** | Imp, Demon Brute, Night Stalker, Hexling, Frost Fiend, Demon Warlord, Gargoyle, Runner, Necromancer, ShieldBearer |
| 🌤️ **Dynamic Weather** | Sunny, Rainy, Snowy, Stormy with visual effects and gameplay impact |
| ⚡ **Wave System** | Progressive difficulty with boss waves every 5 waves |
| 🗺️ **Mini-map** | Real-time overview of battlefield |
| 📊 **Upgrade System** | 4 levels per tower with visual evolution |
| 💰 **Gold Economy** | Earn gold from kills and wave completion |
| 🎯 **Special Abilities** | Homing, chaining, splash damage, dots, slows |

---

## 🎮 How to Play

1. **Select a tower** from the bottom bar
2. **Click on the map** to place it
3. **Click "Start Wave"** to begin
4. **Upgrade/Sell** towers by clicking on them
5. **Survive** as many waves as possible!

---

## 🌤️ Weather Effects

| Weather | Effect |
|---------|--------|
| ☀️ **Sunny** | Fire towers +20% damage |
| 🌧️ **Rainy** | Ice towers +10% damage, enemies slower |
| ❄️ **Snowy** | Ice towers +40% damage, enemies -25% speed |
| ⛈️ **Stormy** | Lightning visuals, enemies faster |
